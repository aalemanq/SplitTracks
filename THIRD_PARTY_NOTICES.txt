StemForge 0.2.0

Personal-use build. No AI model weights are bundled.

Bundled third-party executable:
- yt-dlp 2026.07.04, downloaded from the official yt-dlp release endpoint.
  It is used only to download a single YouTube video as temporary local WAV audio.

Runtime dependencies discovered from Ubuntu:
- Python 3
- GTK 4 via PyGObject
- GStreamer 1.x
- FFmpeg

The Ubuntu package manager supplies the licenses for runtime dependencies.
